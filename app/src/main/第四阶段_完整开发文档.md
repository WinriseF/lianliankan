## 一、项目概述

### 1.1 项目简介

本项目实现了一款经典的 **连连看配对消除游戏**，运行在 Android 平台（API 24+）。游戏采用 8列 × 9行 的棋盘布局，随机生成 36 对动物图案。玩家通过点击两个相同图案的动物进行配对消除，配对路径最多允许 **2个拐点**（即最多3段直线），路径不能穿过未消除的方块，但可以沿棋盘外边框绕行。游戏提供 **2分钟限时** 模式，支持三种难度等级，并包含完整的胜负判定、排行榜、多媒体和系统组件交互功能。

### 1.2 功能亮点

- 🎮 **经典连连看玩法**：8×9棋盘，路径查找支持0/1/2个拐点
- 🎨 **三种难度**：简单（10种动物）、中等（15种）、困难（25种）
- ⏱️ **限时模式**：2分钟倒计时，最后30秒红色警告
- 🧩 **智能棋盘生成**：Fisher-Yates洗牌 + 可解性验证，避免死局开局
- 🔊 **多媒体支持**：背景音乐Service + 多种音效
- 📊 **四大组件全覆盖**：Activity / Service / BroadcastReceiver / ContentProvider
- 📡 **三种消息机制**：Intent / Broadcast / Notification
- 💾 **数据持久化**：SharedPreferences + SQLite + ContentProvider
- 🧭 **Navigation导航**：4个Fragment页面，底部导航栏切换

## 四、核心算法详解

### 4.1 连连看路径查找算法

**规则定义：** 两个格子可以消除 ↔ 存在一条连接路径满足：
1. 路径由水平/垂直线段组成
2. 线段转折点（拐点）不超过 **2个**（最多3段直线）
3. 路径经过的所有中间格子必须已消除（matched=true）或位于棋盘外

**算法思路（三层递进）：**

```
isLinkable(A, B, board):
    ├─ 基础检查：A==B? ID相同? 已匹配? → false
    │
    ├─ ① 0拐点（直线连接）
    │   ├─ 同行(ra==rb): 检查(ra, min(ca,cb)+1)到(ra, max(ca,cb)-1)全为空
    │   └─ 同列(ca==cb): 检查(min(ra,rb)+1, ca)到(max(ra,rb)-1, ca)全为空
    │
    ├─ ② 1拐点（L形连接）
    │   ├─ 拐点(ra, cb): isLineEmpty(A→(ra,cb)) && isLineEmpty((ra,cb)→B)
    │   └─ 拐点(rb, ca): isLineEmpty(A→(rb,ca)) && isLineEmpty((rb,ca)→B)
    │
    └─ ③ 2拐点（Z/U形连接）
        ├─ X型：遍历行r∈[-1, ROWS]，检查 A→(r,ca)→(r,cb)→B（三段线全通）
        └─ Y型：遍历列c∈[-1, COLS]，检查 A→(ra,c)→(rb,c)→B（三段线全通）
```

**关键实现细节：**
- 棋盘外的虚拟行列（row=-1, row=ROWS, col=-1, col=COLS）始终视为"可通过"
- `isLineEmpty()` 函数只检查**起点和终点之间的格子**（不包含端点）
- 拐点本身必须是"空的"（已消除或棋盘外）

**时间复杂度：** O(rows + cols) ≈ O(13)，非常高效

### 4.2 棋盘生成算法

```
generateBoard(rows=9, cols=8, difficulty):
    ① 根据难度获取动物种类数：easy=10, medium=15, hard=25
    ② 创建72个格子的配对数组：每2个格子为一对，使用相同颜色值
    ③ Fisher-Yates 洗牌算法打乱数组顺序
    ④ 将数组映射为AnimalItem列表（每个包含animalId, row, col）
    ⑤ 调用 hasAnyLinkablePair() 检测棋盘是否存在可消除配对
       ├─ 存在 → 返回该棋盘 ✅
       └─ 不存在 → 重新洗牌，最多尝试200次
    ⑥ 超过200次仍无解 → 直接返回（允许死局开局）
```

**生成的颜色值：** 25种预定义的鲜艳颜色（如 0xFFFF5252 红色、0xFF2196F3 蓝色等），通过 `getColorForAnimalIndex(index % animalTypes)` 循环选取。

### 4.3 胜负判定逻辑

```
checkGameState():
    ├─ isGameWon(): 遍历所有72个格子，全部 matched → 胜利！
    │   → 跳转 GameResultActivity，显示"恭喜通关" + 得分 + 用时
    │
    └─ !isGameActive 时不检测
    
    ├─ hasAnyLinkablePair(): 双重循环遍历所有未匹配的相同ID配对
    │   对每一对调用 isLinkable()
    │   ├─ 存在可消除配对 → 游戏继续
    │   └─ 不存在 → 死局！
    │       → 跳转 GameResultActivity，显示"无可消除配对"
    
    └─ 倒计时归零 → 超时失败！
        → 跳转 GameResultActivity，显示"时间到！"
```

### 4.4 得分计算规则

```
得分 = 每对基础分 × 难度系数
     = 10 × (difficulty + 1)
     
简单模式（difficulty=0）：每对 10 分
中等模式（difficulty=1）：每对 20 分  
困难模式（difficulty=2）：每对 30 分
满 分：简单360 / 中等720 / 困难1080
```

- `onPause()` → `stopTimer()` 暂停计时
- `onResume()` → 重建 SoundManager
- `onDestroyView()` → 停止计时器 + 释放 SoundManager

**格子状态渲染：**

| 状态 | 背景色 | 文字 | 透明度 |
|------|--------|------|--------|
| 已消除 | 透明 | ""（空） | 0.3 |
| 选中1 | #FFD54F（金黄） | Emoji | 1.0 |

**格子尺寸计算：** `屏幕宽度 / 10`（留出边距空间）

### 5.3 MusicService（背景音乐Service）

**实现要点：**
- 使用 `startService()` 方式启动（非 bindService）
- 播放时调用 `startForeground()` 成为前台Service（Android 8+ 限制）
- MediaPlayer 设置 `setLooping(true)` 循环播放
- 创建独立的通知渠道 "music_channel"
- 在 `onDestroy()` 中 `release()` 释放资源

**启动/停止控制：**
```java
// 启动音乐
Intent intent = new Intent(context, MusicService.class);
intent.setAction(MusicService.ACTION_PLAY);
context.startService(intent);

// 暂停音乐
intent.setAction(MusicService.ACTION_PAUSE);
context.startService(intent);

// 停止音乐
intent.setAction(MusicService.ACTION_STOP);
context.startService(intent);
```

### 5.4 HeadsetReceiver（耳机插拔广播）

**注册方式：** 在 AndroidManifest.xml 中**静态注册**
```xml
<receiver android:name=".receiver.HeadsetReceiver" android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.HEADSET_PLUG" />
    </intent-filter>
</receiver>
```

**处理逻辑：**
- `state == 0`（拔出）：启动 MusicService 的 PAUSE Action
- `state == 1`（插入）：暂不处理（可扩展为自动恢复播放）

### 5.5 GameResultReceiver（游戏结果接收器）

**核心功能：**
1. 接收 `ACTION_GAME_WIN` 广播
2. 提取分数、用时、难度等数据
3. 调用 `saveResultToDb()` 保存到 SQLite（通过 ContentProvider）
4. 调用 `showCongratulationsNotification()` 发送胜利通知
5. 启动 `GameResultActivity` 显示结果

**保存数据到数据库：**
```java
public static void saveResultToDb(Context context, String result, int score,
                                   int timeUsed, int difficulty) {
    android.content.ContentValues values = new android.content.ContentValues();
    values.put(RankContract.RankEntry.COLUMN_PLAYER_NAME, 
               PreferenceUtil.getPlayerName(context));
    values.put(RankContract.RankEntry.COLUMN_SCORE, score);
    values.put(RankContract.RankEntry.COLUMN_TIME_USED, timeUsed);
    values.put(RankContract.RankEntry.COLUMN_DIFFICULTY, difficulty);
    values.put(RankContract.RankEntry.COLUMN_TIMESTAMP, 
               new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new Date()));
    context.getContentResolver().insert(RankContract.RankEntry.CONTENT_URI, values);
}
```

### 5.6 RankProvider（排行榜ContentProvider）

**URI设计：**
```
content://com.example.lianliankan.rankprovider/ranks          → 查询全部
content://com.example.lianliankan.rankprovider/ranks/#        → 查询单条
```

**CRUD操作：**
- query()：按分数降序排列
- insert()：插入新记录后 notifyChange()
- delete()：支持清空全部记录
- update()：预留

### 5.7 RankDatabaseHelper（SQLite数据库帮助类）

**建表SQL：**
```sql
CREATE TABLE rankings (
    _id INTEGER PRIMARY KEY AUTOINCREMENT,
    player_name TEXT NOT NULL,
    score INTEGER NOT NULL,
    time_used INTEGER NOT NULL,
    difficulty INTEGER NOT NULL,
    timestamp TEXT NOT NULL
);
```

**升级策略（onUpgrade）：** DROP 旧表 → 重建（版本1暂不需要升级逻辑）

### 5.8 SettingsFragment（参数设置）

**界面元素：**
1. RadioGroup：三档难度（简单/中等/困难），点击立即保存到 SharedPreferences
2. Switch：音效开关
3. Switch：背景音乐开关，切换时发送广播通知 MusicService
4. 重置按钮：恢复所有默认设置

**设置持久化：**
```java
// 保存难度
PreferenceUtil.saveDifficulty(context, difficulty);
// 保存音效开关
PreferenceUtil.saveSoundEnabled(context, isChecked);
// 保存背景音乐开关
PreferenceUtil.saveMusicEnabled(context, isChecked);
```

### 5.9 PreferenceUtil（SharedPreferences工具）

**存储结构（文件名：lianliankan_prefs）：**
```
├── difficulty (int, default=0)        → 难度等级
├── sound_enabled (boolean, default=true) → 音效开关
├── music_enabled (boolean, default=true) → 音乐开关
└── player_name (String, default="玩家")  → 玩家名称
```

### 5.10 通知机制设计

**通知渠道（Android 8+ 必须）：**

| 渠道ID | 名称 | 重要性 | 用途 |
|--------|------|--------|------|
| `time_warning` | 时间提醒 | HIGH | 倒计时30秒提醒 |
| `game_result` | 游戏结果 | HIGH | 胜利/失败通知 |
| `music_channel` | 背景音乐 | LOW | Service前台通知 |

### 7.3 音频素材补充

项目 `res/raw/` 目录下需要 6 个音频文件。如果没有现成素材，有以下替代方案：

**方案A：使用系统默认提示音**  
修改 `SoundManager.java` 中所有 `R.raw.xxx` 为：
```java
MediaPlayer.create(context, android.provider.Settings.System.DEFAULT_NOTIFICATION_URI)
```

**方案B：下载免费素材**
- 访问 [freesound.org](https://freesound.org) 搜索关键词：
  - `notification click` → 点击音效
  - `game match` → 消除音效
  - `game over` → 失败音效
  - `victory fanfare` → 胜利音效
  - `background music game` → 背景音乐

### 7.4 常见问题排查

| 问题 | 解决方案 |
|------|---------|
| Gradle Sync 失败 | 检查网络连接，确认 build.gradle 中的版本号正确 |
| R.java 找不到 | Build → Clean Project → Rebuild Project |
| 运行时闪退 | 检查 AndroidManifest.xml 中所有组件是否注册 |
| 棋盘无动物显示 | 确认 `res/drawable/card_background.xml` 存在 |
| 崩溃在 GameFragment | 确认 timeRemaining 已初始化（= 120） |
| 排行榜为空 | 正常现象，完成一局游戏后才会保存数据 |
