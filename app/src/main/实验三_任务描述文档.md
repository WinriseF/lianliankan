## 三、详细实现说明

### 3.1 SoundManager（音效管理器）

**文件路径：** `util/SoundManager.java`

```java
public class SoundManager {
    private MediaPlayer clickSound;    // 点击音
    private MediaPlayer matchSound;    // 消除音
    private MediaPlayer failSound;     // 失败音
    private MediaPlayer winSound;      // 胜利音
    private MediaPlayer loseSound;     // 结束音

    // 每个音效独立MediaPlayer，播放前release旧的再create新的
    // 所有方法首先检查 PreferenceUtil.isSoundEnabled(context)
    // Fragment.onDestroyView() 调用 release() 统一清理
}
```

**调用时机：**

| 触发场景 | 调用方法 |
|---------|---------|
| 点击任意格子 | `playClickSound()` |
| 配对消除成功 | `playMatchSound()` |
| 配对失败（ID不同） | `playFailSound()` |
| 游戏胜利 | `playWinSound()` |
| 游戏失败（超时/死局） | `playLoseSound()` |

### 3.2 MusicService（背景音乐服务）

**文件路径：** `service/MusicService.java`

**启动方式：** `startService()`（非 bindService），生命周期跟随整个应用

**控制协议：**
```java
// 启动/播放
Intent intent = new Intent(context, MusicService.class);
intent.setAction(MusicService.ACTION_PLAY);
context.startService(intent);

// 暂停
intent.setAction(MusicService.ACTION_PAUSE);
context.startService(intent);

// 停止（释放资源）
intent.setAction(MusicService.ACTION_STOP);
context.startService(intent);
```

**前台Service机制：**
- 播放时自动升级为前台Service，显示通知栏图标
- 创建 `music_channel` 通知渠道（Android 8+）
- 用户点击通知回到 MainActivity

### 3.3 HeadsetReceiver（耳机插拔监听）

**注册方式：** AndroidManifest.xml 静态注册

```xml
<receiver android:name=".receiver.HeadsetReceiver" android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.HEADSET_PLUG" />
    </intent-filter>
</receiver>
```

**处理逻辑：**
```java
int state = intent.getIntExtra("state", -1);
if (state == 0) {
    // 耳机拔出 → 暂停背景音乐
    context.startService(new Intent(context, MusicService.class)
        .setAction(MusicService.ACTION_PAUSE));
} else if (state == 1) {
    // 耳机插入 → 可选：恢复播放
}
```

### 3.4 GameResultReceiver（游戏结果广播接收器）

**注册方式：** MainActivity 中动态注册（LocalBroadcastManager）

```java
// onResume() 中注册
LocalBroadcastManager.getInstance(this).registerReceiver(
    gameResultReceiver, filter);

// onPause() 中注销
LocalBroadcastManager.getInstance(this).unregisterReceiver(
    gameResultReceiver);
```

**接收到广播后的处理链：**
```
接收 ACTION_GAME_WIN
  → 提取 score/time_used/difficulty
  → saveResultToDb() 保存到SQLite（通过ContentProvider）
  → showCongratulationsNotification() 发送通知
  → startActivity(GameResultActivity) 跳转结果页
```

### 3.5 Preference设置系统

**SharedPreferences 存储结构：**
```
文件名：lianliankan_prefs
├── difficulty       (int)     默认值 0 (EASY)
├── sound_enabled    (boolean) 默认值 true
├── music_enabled    (boolean) 默认值 true
└── player_name      (String)  默认值 "玩家"
```

**Preference XML 页面结构：**
```xml
<PreferenceScreen>
  <PreferenceCategory title="游戏设置">
    <ListPreference         → 难度选择（simple/medium/hard）
    <SwitchPreferenceCompat → 音效开关
    <SwitchPreferenceCompat → 背景音乐开关
  </PreferenceCategory>
  <PreferenceCategory title="关于">
    <Preference → 关于连连看（显示版本信息）
    <Preference → 清除排行榜记录
  </PreferenceCategory>
</PreferenceScreen>
```
