# 实验一：核心游戏主界面 — 任务描述文档

## 一、选题内容

**项目名称：** 连连看（动物配对消除游戏）

**游戏概述：** 8列 × 9行 的棋盘上随机分布36对动物图案。玩家点击两个相同动物进行配对，配对路径最多允许2个拐点（即最多3段直线），路径不能穿过未消除的方块，但可沿棋盘外边框绕行。默认2分钟限时模式，在规定时间内完成全部消除判定为胜利。

**核心玩法流程：**
```
点击选中第一个动物 → 选中高亮显示
                → 点击第二个动物
                    → ID相同 + 路径可达 → 消除配对 + 计分
                    → ID不同 或 不可达 → 取消选中
                → 检测游戏状态（胜利/失败/继续）
```

## 三、功能实现详解

### 3.1 核心游戏引擎 GameEngine

**文件路径：** `util/GameEngine.java`

```java
// 关键常量
BOARD_ROWS = 9, BOARD_COLS = 8, TOTAL_CELLS = 72, PAIRS_COUNT = 36
DIFFICULTY_EASY = 0, DIFFICULTY_MEDIUM = 1, DIFFICULTY_HARD = 2
DIFFICULTY_ANIMAL_COUNTS = [10, 15, 25]

// 核心方法
isLinkable(A, B, board)  → boolean  // 判断两个格子能否连接
findPath(A, B, board)    → List<Point> // 获取连接路径（用于绘制连线）
isGameWon(board)         → boolean  // 全部消除=胜利
hasAnyLinkablePair(board) → boolean  // 存在可消除配对
```

**路径查找算法：**

| 步骤 | 检查内容 | 条件 |
|------|---------|------|
| Step 1 | 基础检查 | 两格不同ID / 未匹配 / 非同格 |
| Step 2 | 0拐点直线 | 同行或同列，中间全空 |
| Step 3 | 1拐点L形 | 拐点(ra,cb)或(rb,ca)为空，两线段畅通 |
| Step 4 | 2拐点Z/U形 | 遍历虚拟行列，X型+Y型三段全通 |

**棋盘外虚拟行列处理：** row=-1 / row=9 / col=-1 / col=8 的格子视为始终可通行，用于支持路径沿棋盘外框绕行。

### 3.2 棋盘生成器 GameGenerator

**文件路径：** `util/GameGenerator.java`

```java
generateBoard(9, 8, difficulty):
    ① 确定动物种类数：easy→10, medium→15, hard→25
    ② 创建36对配对数组（72个值），使用getColorForAnimalIndex()获取颜色
    ③ Collections.shuffle() 洗牌
    ④ 构建临时棋盘，hasAnyLinkablePair()检测可解性
    ⑤ 有解→返回；无解→重新洗牌，最多200次
    ⑥ 超时→返回最后结果（fallback）
```

### 3.3 数据模型 AnimalItem

**文件路径：** `model/AnimalItem.java`

| 属性 | 类型 | 说明 |
|------|------|------|
| animalId | int | 动物颜色值（唯一标识，用于配对判断） |
| imageResId | int | 图片资源ID（与animalId相同，预留扩展） |
| row | int | 行号 0~8 |
| col | int | 列号 0~7 |
| matched | boolean | 是否已消除 |

### 3.4 棋盘适配器 BoardGridAdapter

**文件路径：** `adapter/BoardGridAdapter.java`

**五状态渲染：**
- 已消除 → 透明背景 + 空文字 + 0.3透明度
- 选中1 → 金黄色(#FFD54F)背景 + Emoji
- 选中2 → 橙红色(#FF8A65)背景 + Emoji
- 路径高亮 → 浅蓝色(#81D4FA)背景 + Emoji
- 默认 → 动物颜色背景 + Emoji + 自动对比色文字

### 3.5 计时器实现

```java
// 使用Timer.scheduleAtFixedRate，精确1秒间隔
timer = new Timer();
timer.scheduleAtFixedRate(new TimerTask() {
    @Override
    public void run() {
        handler.post(() -> {
            if (!isGameActive) return;
            timeRemaining--;
            updateTimerUI();
            if (timeRemaining == 30) showTimeWarningNotification(); // 最后30秒通知
            if (timeRemaining <= 0) onGameFail("time_up");
        });
    }
}, 1000, 1000); // delay=1s, period=1s
```

## 四、关键问题与解决方案

| 问题 | 风险 | 解决方案 |
|------|------|---------|
| 棋盘开局存在可直接消除配对 | 高 | `hasAnyLinkablePair()` 检测 + 最多200次重新洗牌 |
| 路径查找算法遗漏部分情况 | 高 | 三层递进检测 + 棋盘外虚拟行列支持，72格内全覆盖 |
| Fragment切换丢失游戏状态 | 中 | `onSaveInstanceState` 保存5个字段 + matched数组 |
| 倒计时精度漂移 | 低 | Timer + Handler组合，每次tick基于系统时间更新UI |
| 初始棋盘全部可匹配（罕见） | 低 | 200次重试后直接返回，至少保证棋盘有效 |
