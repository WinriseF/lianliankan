# 实验二：菜单系统与导航完善 — 任务描述文档

## 一、选题内容

延续实验一的连连看游戏基础，本次实验重点完善 **菜单系统** 和 **导航功能**，实现完整的用户交互体验。

### 新增/完善功能：
- 选项菜单（OptionsMenu）：难度设置、关于弹窗
- 上下文菜单（ContextMenu）：棋盘区域长按弹出打乱重排/重新开始/暂停
- 难度选择功能（三档RadioGroup切换）
- Intent跳转机制（Activity间数据传递）
- 路径高亮动画绘制

## 三、功能实现详细说明

### 3.1 选项菜单实现流程
```
MainActivity.onCreateOptionsMenu()
  → getMenuInflater().inflate(R.menu.main_options_menu, menu)
  → 菜单显示"难度设置"（图标+文字）和"关于"两个选项

MainActivity.onOptionsItemSelected()
  → 点击"难度设置" → FragmentTransaction.replace(SettingsFragment) + backStack
  → 点击"关于"     → AlertDialog.show("连连看 v1.0\n课程作业\n规则说明...")
```

### 3.2 上下文菜单实现流程
```
RecyclerView item long click
  → v.showContextMenu() 触发弹出

onCreateContextMenu(menu, v, menuInfo)
  → getMenuInflater().inflate(R.menu.board_context_menu, menu)
  → 显示"打乱重排" | "重新开始" | "暂停游戏"

onContextItemSelected(item)
  → 打乱重排：GameGenerator.generateBoard() 重新生成 → adapter.notifyDataSetChanged()
  → 重新开始：board重置 + timer重置 + score归零 + UI更新
  → 暂停游戏：stopTimer() / startTimer() 切换
```

### 3.3 Intent数据传递格式
```
Key              | Type   | 示例值
-----------------|--------|-------------
"result"         | String | "win" / "time_up" / "deadlock"
"score"          | int    | 360
"time_used"      | int    | 95  （秒）
"difficulty"     | int    | 0 / 1 / 2
"pairs_cleared"  | int    | 36
```

## 四、遇到的问题与解决方案

| 问题 | 严重程度 | 解决方案 |
|------|---------|---------|
| Fragment切换时游戏计时器丢失 | 中 | 使用 `onSaveInstanceState` 保存 isGameActive + timeRemaining，onResume重建计时器 |
| 长按棋盘不弹出上下文菜单 | 低 | 确保 `registerForContextMenu()` 已调用，且RecyclerView item长按触发 `showContextMenu()` |
| Intent传递数据在旋屏后丢失 | 中 | 使用 `onSaveInstanceState` Bundle 保存所有游戏状态数据 |
| 选项菜单在非Game页面显示不合适 | 低 | 各Fragment设置 `setHasOptionsMenu(true)`，MainActivity根据当前Fragment调整菜单 |
| 难度切换后立即生效（当前游戏中途变化） | 低 | 设计为"下次游戏生效"，SettingsFragment中提示"难度已修改，下次游戏生效" |

## 六、自评与注意事项

### 易扣分项提醒 ⚠️
1. **上下文菜单未正确注册** → 确保 `registerForContextMenu(view)` 或item正确设置长按监听
2. **选项菜单不显示** → `onCreateOptionsMenu()` 必须返回 `true`
3. **难度切换未持久化** → 必须保存到 `SharedPreferences` 并在重新进入时读取
4. **Intent数据丢失** → `putExtra()` 和 `getIntExtra()` 的 key 必须完全一致
5. **结果页面未显示具体信息** → 需要展示用时、分数、难度、消除对数等完整信息
